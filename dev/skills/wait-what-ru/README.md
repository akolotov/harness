# wait-what-ru

Use this skill when the last message of the agent is not clear to you. The skill tells
the agent to explain its conclusion again, in Russian:

1. First, the agent gives short context.
2. Then, the agent explains the current result.
3. The agent uses simple, unambiguous Russian that follows the ASD-STE100 principles.

You must invoke this skill by name. It does not start on its own.

## Origin

This skill is a Russian version of the
[`wait-what`](https://github.com/mattpocock/skills/tree/main/skills/productivity/wait-what)
skill by Matt Pocock, published under the MIT License.
